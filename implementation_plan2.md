# Plano de Implementação: Captura de Newsletter (Fio Vermelho)

Este plano descreve a implementação técnica de uma seção de Newsletter elegante e minimalista na página inicial de **"Fio Vermelho"** (`index.html`), projetada sob a estética noir (preto e vermelho) do site. Ela permitirá a captura de leads (e-mails) integrando diretamente ao Supabase com fallback de armazenamento local para desenvolvimento/modo offline.

---

## Banco de Dados (Supabase)

### Nova Tabela: `newsletter`
Como os visitantes na página inicial ainda não estão autenticados (antes do fluxo de pagamento/login), a tabela precisa permitir inserções públicas (anônimas). Portanto, habilitamos o Row Level Security (RLS) e criamos uma política de `INSERT` aberta, mas mantemos a leitura fechada para segurança de dados.

```sql
-- 1. Criar a tabela de newsletter se não existir
CREATE TABLE IF NOT EXISTS public.newsletter (
    id BIGINT GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
    email TEXT UNIQUE NOT NULL,
    created_at TIMESTAMPTZ DEFAULT timezone('utc'::text, now()) NOT NULL
);

-- 2. Habilitar RLS (Row Level Security) para segurança jurídica
ALTER TABLE public.newsletter ENABLE ROW LEVEL SECURITY;

-- 3. Permitir que qualquer visitante anônimo se inscreva (INSERT público)
CREATE POLICY "Permitir inserções públicas (Newsletter)" 
ON public.newsletter 
FOR INSERT 
TO public 
WITH CHECK (true);

-- 4. Permitir leitura apenas para administradores autenticados (opcional, para segurança)
CREATE POLICY "Permitir leitura apenas para administradores" 
ON public.newsletter 
FOR SELECT 
TO authenticated 
USING (true);
```
